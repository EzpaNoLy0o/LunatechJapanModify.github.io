## 未検証・残っている問題点

1. **Windows 実機での動作は未検証**（開発環境は Linux）。依存ライブラリはすべて Windows 用 wheel があり、
   Windows 固有の処理（日本語パスの OCC I/O 回避、%APPDATA% 設定、bat スクリプト）は実装済み。
   初回は `run_tests.bat` と `LJM_ReverseEngineering.exe --self-test` での確認を推奨します。
2. **実際の POP 4 スキャンデータでは未検証**（合成データのみ）。実データでは自動閾値・スマート選択の角度許容の調整が必要な可能性があります。
3. Windows 用 EXE は未作成（Linux でのビルドとセルフテストのみ確認）。Linux 版 onedir は約 1.5GB（VTK・OCC・Qt を含む）。
4. 1000 万面を超える超大規模メッシュでの操作性は未評価（LOD・選択処理は NumPy ベクトル化済み）。
5. 3D ビュー内のラベルは VTK の標準フォントのため英数字のみ。
6. Bスプライン曲面はトリム無し（矩形範囲）。複雑な曲面は領域を分割してフィットしてください。
7. STEP 内の形状名は ASCII のみ（日本語名は除去されます）。
