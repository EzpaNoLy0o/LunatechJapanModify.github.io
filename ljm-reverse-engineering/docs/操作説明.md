# LJM Reverse Engineering 操作説明

## 1. 画面構成

| 位置 | 内容 |
|---|---|
| 上部 | メニューバーとリボン（ファイル / 編集 / 表示 / スキャンデータ / 測定 / 位置合わせ / 形状認識 / CAD再構築 / エクスポート / 設定） |
| 左 | **モデルツリー**: メッシュ・点群・座標系・基準点・基準軸・平面・円筒・穴・球・断面曲線・CAD形状・測定結果。チェックで表示/非表示、F2 で名前変更、Delete で削除、右クリックでメニュー、ダブルクリックでズーム |

| 右 | **プロパティ**: 選択したオブジェクトの寸法・座標・方向・フィット結果。白字の値はダブルクリックで編集（ベクトルは `x, y, z`） |

## 3. 基本ワークフロー

### 3.1 スキャンデータの読込
1. 「ファイル > メッシュ/点群をインポート」（`Ctrl+I`）で STL / OBJ / PLY を選択（複数可）
2. **単位の確認**ダイアログで単位を選択（Revo Scan の出力は通常 mm）。寸法が極端に小さい/大きいと警告が出ます
3. 頂点カラー付き PLY/OBJ は「表示 > スキャンカラー表示切替」でカラー表示

元のスキャンデータはプロジェクト内に保持され、編集後も「スキャンデータ > オリジナルに戻す」で復元できます。

### 3.2 領域の選択
- **スマート選択（G）**: 面をクリックすると、隣接面の角度差が許容値（既定 6°）以内で連続する領域を選択します。
  平面・円筒面（穴の内壁など）を選ぶのに最適です。平面だけを選びたい場合は「設定 > スマート選択: 開始面からの最大偏差」を 10° 程度に。
- **矩形選択（R）**: 左ドラッグの矩形内。既定では前面に見えている面のみ（設定で変更可）。
- **ブラシ選択（B）**: クリック/ドラッグした位置の半径内。

穴埋めで作られた「人工面」はピンクで表示され、既定ではフィットから除外されます。

### 3.3 平面・円筒・穴中心の認識
| 目的 | 操作 |
|---|---|
| 平面 | 面を選択 → 「形状認識 > 平面フィット」（`Ctrl+1`） |
| 円筒（ブッシュ・パイプ・穴） | 円筒面を選択 → 「円筒フィット」（`Ctrl+2`）。一部しかスキャンできていなくても可（不確かさを表示） |
| 穴中心（内壁から） | 穴のある平面をツリーで選択 → 穴の内壁を選択 → 「穴中心（内壁から）」。軸と平面の交点が穴中心になります |
| 穴中心（断面から） | 平面をツリーで選択 → 「穴中心（平面断面から）」→ 穴の近くをクリック。内周が不完全でも円フィットで中心を求めます |
| 平面上の穴を自動検出 | 平面をツリーで選択 → 「平面上の穴を自動検出」（径範囲・許容偏差を指定） |
| 円（穴の縁） | 縁付近を選択 → 「円フィット」 |
| 基準点 / 基準軸 | クリック、3平面の交点、円筒/穴の軸、2点、2平面の交線から作成 |

結果のプロパティには **入力点数・使用点数・インライア率・RMS 残差・最大残差・閾値・推定不確かさ(1σ)・円周カバー範囲・元のスキャンファイル・作成時の座標系** が表示されます。
⚠ の警告（円弧範囲が狭い・インライア率が低い等）が出た場合は選択範囲を見直してください。

閾値などは「形状認識 > フィッティング設定」で変更できます（0 = 残差の MAD から自動決定。使用した閾値は結果に記録）。

### 3.4 座標系
- 「位置合わせ > 座標系: 3平面 (3-2-1)」: 第1平面の法線 = Z、第2平面 = X 方向、3平面の交点 = 原点（部品の基準面で位置決め）
- 「座標系: 平面＋軸」: Z = 平面法線、X = 軸の投影、原点 = 軸と平面の交点
- 「座標系: 3点から」「軸＋点」「数値入力」
- 作成時に「作業座標系に設定」を選ぶと、以降の座標表示・CSV 出力・ビュー方向がその座標系になります
- 「選択座標系をワールドに合わせる」: すべてのオブジェクトを移動して座標系をワールドに一致させます（STEP をその座標系で出力したいとき）

### 3.5 測定
- 点を使う測定（2点距離・角度・座標・投影距離・点-平面）は、コマンド実行後にモデルをクリックします。
  基準点・穴中心・座標系原点・軸端・平面中心の近く（12 px 以内）をクリックするとその点に**スナップ**します。
- 「選択要素間の測定」（`M`）: ツリーで 2 要素を選ぶと種類に応じて自動判定します
  - 平面-平面: 角度・平行/直角判定・距離 / 軸-軸（円筒・穴・基準軸）: 最短距離・角度・同軸度 / 穴-穴・点-点: 中心間距離 / 点-平面 / 点-軸 / 軸-平面
- 測定結果はモデル上に寸法線とラベルで表示され、ツリーの「測定結果」に保存されます。
- **スケール確認・補正**: 既知寸法（ノギス実測値など）と比較してスケール係数を算出し、必要なら全体に補正を適用します。

### 3.6 複数スキャンの位置合わせ
1. 「対応点による位置合わせ」: 移動側 → 固定側 の順に同じ特徴点を交互にクリック（3 組以上）
2. 「ICP 精密位置合わせ」: 対応点でおおまかに合わせた後に実行（RMS 残差・重複率を表示）
3. 「位置合わせ評価」: 2 データ間の重複率・残差

### 3.7 断面と CAD 再構築
1. 「CAD再構築 > 断面作成: X/Y/Z」（または要素基準・連続断面）
2. 断面をツリーで選択 → 「断面をスケッチ化（直線・円弧）」: 許容誤差内で直線・円弧・円に自動分割（シアン色で表示）
3. 「押し出し」: 閉じた断面から（内側の曲線は穴として）ソリッドを作成
4. 「回転体」: 軸を含む断面（要素基準で円筒/軸を選択して作成）＋ 軸 → 回転体
5. 「ロフト曲面」: 複数の断面（連続断面）から曲面/ソリッド
6. 「Bスプライン曲面フィット」: 選択領域に制御点数を指定して曲面をフィット（残差を表示）
7. 「要素から CAD 形状を作成」: 平面→面、円筒→円筒面/円柱、穴→円エッジ/円柱、球→ソリッド、軸→エッジ
8. 「ブーリアン」: 2 つの CAD 形状の結合/差/共通
9. 「CAD-メッシュ偏差解析」: メッシュ頂点から CAD 面までの符号付き距離をカラーマップ表示（統計値はプロパティに保存）

### 3.8 出力
| 出力 | 内容 |
|---|---|
| STEP | 再構築した CAD 形状。**出力後に再読込して面の種類・ソリッド数・体積・表面積・外形・半径を検証**し、結果を表示。基準軸・穴をエッジとして含めることも可。基準点・穴中心・軸は `*_datums.csv / .json` にも出力 |
| DXF | 断面曲線。2D（断面平面座標、直線/円弧/円/スプライン）または 3D ポリライン |
| CSV | 座標一覧（基準点・穴中心・円筒・軸・平面・座標系, 作業座標系）、測定結果、点間距離マトリクス |
| JSON | プロジェクト情報 |
| メッシュ | STL / OBJ / PLY |

### 3.9 プロジェクト
「ファイル > プロジェクトを保存」で `.ljmre`（ZIP 形式）に保存します。
読み込んだメッシュ（元データと編集後）、配置、単位、座標系、抽出した幾何形状、測定結果、CAD 形状（BRep）、表示設定、処理パラメータを含み、再度開いて作業を継続できます。

## 4. 精度管理と安全上の注意

- 各要素のプロパティ「精度管理」で **安全上重要** と **実測確認済み / 実測値・確認メモ** を記録できます。
  安全上重要で未確認の要素があると、CSV/STEP 出力時に警告し、出力ファイルにも記録します。ツリーでは ⚠（未確認）/ ✔（確認済み）で表示されます。
- 表示桁数（設定）は丸めであり、精度ではありません。
- 円筒の円周カバー範囲が狭い場合（例: 120° 未満）は直径・軸位置の不確かさが大きくなります（1σ を表示）。
- スキャナ自体の精度・スケール誤差はソフトでは補正できません。既知寸法で確認してください。

## 5. 自動車部品向けの使い方の例

### リアサブフレーム（取付点の抽出）
1. 車体取付穴: 穴のある座面を平面フィット → 穴の内壁を選択 → 穴中心（内壁から）
2. アームピボット: ブッシュ外筒/内筒を円筒フィット → 「基準軸: 円筒/穴の軸から」で軸を作成
3. 各要素のプロパティで分類（車体取付穴 / アームピボット / デフマウント 等）と「安全上重要」を設定
4. 基準面から 3-2-1 座標系を作成して作業座標系に設定
5. 「測定 > 取付点一覧」で座標一覧を確認し、CSV・距離マトリクスを出力

### エキゾーストマニホールド / エアロパーツ
- 複数スキャンを対応点 + ICP で同一座標系に配置
- 連続断面 → ロフト、または Bスプライン曲面フィットで曲面を作成し、偏差解析で確認

## 6. トラブルシューティング

| 症状 | 対処 |
|---|---|
| 起動しない | `run_ljm_re_console.bat` でエラーを確認。ログ: `%LOCALAPPDATA%\LJM_ReverseEngineering\logs\ljm_re.log` |
| 画面が真っ黒 / 3D が表示されない | GPU ドライバを更新（OpenGL 3.2 以上が必要）。リモートデスクトップでは表示できない場合があります |
| 動作が重い | 「設定 > 表示LODを使う面数の閾値」を小さく。「スキャンデータ > 簡略化」も有効 |
| フィット結果がおかしい | 選択範囲に別の面（面取り・R部）が含まれていないか確認。スマート選択の角度許容を小さく |
| CAD 機能が無効 | OCP (cadquery-ocp) がインストールされていない。`setup_windows.bat` を再実行 |
