LJM.CFD.Beta. 0.6.2.3

取扱説明書 - WEB版

重要: 本ソフトはBeta版のCFDプレビュー環境です。解析結果は設計比較・傾向把握の参考として使用し、最終的な安全性・法規適合・構造強度・空力性能の保証には使用しないでください。

0. 重要事項・利用条件

必読: LJM.CFD.Beta. 0.6.2.3 は現在開発中の未完成Beta版です。安定動作、すべてのデータ形式との互換性、解析結果の正確性を保証する正式版ではありません。

開発状況

本ソフトは継続的に開発・検証中です。機能、UI、対応形式、解析処理、保存形式は今後の更新で変更される場合があります。現在のプロジェクトが将来版で完全に互換となる保証もありません。

データ形式とKN5

STEP / STP等を中心に検証していますが、同じ拡張子であっても、作成ソフト、モデル構造、面の状態、ソリッド化、データ量等によって読込やメッシュ生成に失敗する場合があります。すべてのデータ形式・すべてのデータで完璧に動作する保証はありません。

KN5形式への対応は現在調整中です。 現段階ではKN5データの完全な互換性・安定動作を保証しておらず、読み込み、形状変換、解析用データ生成等が意図した結果にならない場合があります。

計算結果の扱い

本Beta版の計算結果は、風洞試験、実測値、高精度な商用CFD、十分に検証された解析環境と同等の正確性を保証しません。Drag、Downforce、Lift、Side Force、圧力、流速、Cp等は参考値・傾向確認用として扱い、重要な設計・安全判断を本ソフトの値だけで行わないでください。

2次配布の禁止

LJM.CFD本体、インストーラー、実行ファイル、配布ZIP、改変版・再パッケージ版を、作者の事前許可なく第三者へ転載・2次配布することを禁止します。紹介する場合は公式配布ページのURLを共有してください。第三者ソフトウェアは各権利者のライセンス条件に従います。

フィードバック

ソフトウェアに関する不具合、要望、対応してほしい形式、解析結果への意見は、SNS（X）への投稿も歓迎します。投稿時は【#LJM.CFD】を付けていただくことを推奨します。可能であれば、バージョン、PC構成、入力形式、発生した現象、スクリーンショット等も添えてください。

1. ソフトの概要

LJM.CFD.Beta. 0.6.2.3 は、自動車および自動車部品の外部流れ解析を、OpenFOAMの設定ファイルを直接編集せずGUIから実行するためのBeta版ツールです。CAD読込、風洞領域、四面体メッシュ、OpenFOAM変換、定常RANS計算、空力荷重、3D可視化を一連の操作として扱います。

  • STEP / STP形式の3D CAD読込
  • Yaw / Pitch / Rollによるモデル姿勢変更
  • モデル寸法倍率での仮想風洞生成
  • Gmshによる外部流体四面体メッシュ
  • WSL2上のOpenFOAMへ変換・checkMesh
  • steady incompressibleFluid + k-omega SSTによるCFDプレビュー
  • Drag / Downforce / Lift / Side Force
  • 速度、圧力、k、omega、渦度、Q-criterionの3D可視化
0.6.2.3では境界層プリズムがないため、絶対値よりも形状変更前後の傾向比較を中心に使用してください。

3. 初回セットアップ

  1. 配布ファイルをローカルフォルダへ配置します。
  2. ソース版では setup_windows.bat を初回実行し、Windows側Python環境を構築します。Setup.exe配布版ではインストーラーの案内に従います。
  3. 必要に応じてメッシュ / OpenFOAM / VTKの自己テストを実行します。
  4. LJM.CFDを起動し、ウィンドウタイトルに対象バージョンが表示されることを確認します。

5. 最短手順: STEPから結果表示まで

  1. STEPを開く。
  2. 必要ならYaw / Pitch / Rollを設定して姿勢を適用。
  3. 仮想風洞を生成 / 更新。
  4. 速度、温度、圧力、Ground、乱流強度、Iterationsを設定。
  5. Mesh Qualityを選び、外部メッシュ生成・保存。
  6. OpenFOAMへ変換 + checkMesh。
  7. CFDテスト計算を開始。
  8. 収束後、結果をVTK変換 / 更新。
  9. 断面、流線、表面p/Cp、渦等値面、空力荷重を確認。
モデル姿勢・風洞寸法・メッシュ寸法を変更した場合はメッシュから作り直してください。

6. STEPモデルの準備と読込

STEP / STPを読み込みます。CAD座標はmmとして扱い、Gmsh / OpenFOAMへ渡す際にmへ変換します。

  • 外形が閉じた3Dソリッドを推奨。
  • 極端に小さい面、重複面、自己交差を可能な範囲で整理。
  • 解析不要な内部部品を削除するとメッシュ時間とセル数を抑えられます。

12. OpenFOAM変換とcheckMesh

mesh.mshをWSL2から参照し、gmshToFoamでOpenFOAM形式へ変換後、checkMesh -allTopology -allGeometryを実行します。

主要境界名: inlet / outlet / side_min / side_max / ground / top / body。

失敗時は openfoam_error.txt と openfoam_check.log を確認してください。

20. Beta版の制限事項と推奨運用

KN5: KN5形式への対応は現在調整中で、完全な互換性・安定動作は保証していません。
  • 境界層プリズムなし。
  • Wheel Rotation無効。
  • Wind Yaw / Pitch / AoA無効。モデル側を回転。
  • Internal Flow未完成。
  • Cd / Cl未算出。
  • 定常RANSのため非定常渦放出・時間変動を直接評価しない。
  • 擬似スモークは定常速度場の流線表示。
  • 絶対値より同一条件でのA/B比較を優先。

推奨する比較方法

  1. 速度、風洞倍率、Ground、温度、圧力、乱流強度を揃える。
  2. Mesh QualityとNear/Farを揃える。
  3. 両方とも収束させる。
  4. 荷重差とCp / 床下速度 / Wake / Q-criterionの変化を併せて確認。
  5. 小さな差はFine / Very Fineで再確認。
