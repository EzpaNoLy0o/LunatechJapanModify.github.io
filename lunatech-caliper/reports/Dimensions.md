# Dimensions — Lunatech Titanium Caliper Replica

すべて mm。座標系：X = キャリパー長手（ローター接線）、Y = ローター軸（+Y = アウトボード / ホイール面側）、
Z = ローター半径方向。原点 = ローター回転中心、ローター中心面 Y = 0。数値は `src/validate_model.py` が
**出力 STL を読み戻して** 計測した値です（`build/validation.json`）。

## 1. 外形寸法（キャリパー本体 + ロゴ）

| 項目 | 本モデル | 初期目標 | Bugatti 実物（公表値） | 実物比 |
|---|---|---|---|---|
| 全長 X | **308.6** | 約310 | 410 | 0.75 |
| 全幅 Y | **161.0** | 165〜185 | 210 | 0.77 |
| 全高 Z | **127.6** | 110〜130 | 136 | 0.94 |
| 最大軸寸法 | **308.6** | ≤ 320（推奨 310） | — | — |
| 体積 | 809 cm³ | — | （2.9 kg ≒ 655 cm³ Ti-6Al-4V） | — |

* 自動サイズゲート：生成時に各軸 > 320 mm なら目標全長を縮めて再生成（`generate_caliper.py`）。
  今回の履歴：[{'attempt': 1, 'target_length': 310.0, 'extent': [308.54, 160.99, 127.62]}]
* 全幅は初期目標下限 165 mm をわずかに下回ります（161.0 mm）。幅はローター厚32 + パッド + ピストン
  ストローク + ボア底 + ブリッジで決まり、ホイールスポーク側クリアランス（13.6 mm）を
  優先しました。`main_bridge_y_center` / `inboard_bridge_y` / `bore_depth` を増やせば拡幅できます。

## 2. デフォルメ（非一様縮小）

| 軸 | 実物 → 模型 | 倍率 | 方針 |
|---|---|---|---|
| 長手 | 410 → 309 | 0.75 | ピストン間隔・パッド長を圧縮、両端トラスは角度で確保 |
| 幅 | 210 → 161 | 0.77 | ローター厚 32（実物40想定）に合わせて縮小 |
| 高さ | 136 → 128 | 0.94 | ほぼ維持：アーチ形状・メインブリッジの存在感を優先 |

長手方向のみ強く縮め、高さ方向はほぼ維持しているため、メインブリッジやバイオニック構造が相対的に
小さくなりすぎないようにしています。

## 4. ピストン配置（8ポット対向：外側4 + 内側4、模型用仮設定値）

ピストン軸はローター軸に平行、中心半径 R = 151.25（パッド中心）。
回転方向の入口側（-X）から小径→大径。中心間距離（円弧長）：38.0, 40.0, 42.0 mm。

| # | 径 | 円弧位置 s | 角度 | X | ハウジング外径 |

| スポーク軸方向クリアランス | **13.60**（目標 ≥ 3.0） | OK |

本体外形はホイールパラメータから自動算出される包絡半径 R_cap = バレル内径/2 − 4.0
= 201.0 mm で滑らかにトリムされます。実車ホイールの実測値（バレル最小内径・スポーク裏面形状）を
`parameters.json → wheel` に入れて再生成・再検証してください。

## 6. 主要パラメータ（`src/parameters.json`）

全長 `limits.target_length_mm` / ローター `rotor.*` / ホイール `wheel.barrel_min_inner_diameter`, `wheel.spoke_back_y` /
ピストン径 `piston.diameters` / 中心間 `piston.web_between_bores` / ブリッジ厚 `body.main_bridge_half_thickness_*` /
リブ太さ `body.rib_scale` / ブレンド `body.blend_major|minor` / 開口寸法 `body.opening_scale` /
ロゴ `logo.cap_height, tracking, protrusion, center_angle_deg, radial_offset` / 造形 `fdm.*` / メッシュ `mesh.*`
