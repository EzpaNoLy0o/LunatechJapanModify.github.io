LJM.CFD

Beta 0.6.2.3

自動車の外部空力解析を、できるだけシンプルな操作で実行するために開発中のCFDソフトウェアです。

無料ダウンロード / GitHub Releases 動作環境を見る

配布ファイルがまだ公開されていない場合、Releasesページには最新版が表示されません。

自動車向けCFD

車体・エアロパーツの外部流れを対象に、メッシュ作成からOpenFOAM解析までをGUIから実行します。

流れを可視化

流速、圧力、Cp、流線、渦度、Q-criterionなどの結果を3Dで確認できます。

空力荷重を確認

Drag、Downforce、Lift、Side Forceと、圧力・粘性成分を確認できます。

取扱説明書 / DOCUMENTATION

WEB版の取扱説明書をブラウザで閲覧できます。PDF保存用の印刷レイアウトにも対応しています。

説明書・資料 WEB版を読む

INSTALLATION

01

Setup.exeを取得

GitHub Releasesから最新版のセットアップファイルをダウンロードします。

02

インストール

Setup.exeを実行します。Pythonはアプリ側へ同梱する配布方式を予定しています。

03

CFD環境を確認

CFD計算にはWSL2 / Ubuntu / OpenFOAMが必要です。初回セットアップで確認します。
